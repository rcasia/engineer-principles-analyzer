# Acceptable Use Policy (DRAFT — not in force)

> **Status:** Draft skeleton. Not published, not binding. Must be reviewed
> before the hosted service accepts user input.

**Classification:** Public.
**Assumed product mode:** No hosted service accepts user input yet.

## Sections to complete before accepting user input

- Permitted use: submitting code you are authorised to submit for analysis.
- Prohibited use: submitting others' code without authorisation; uploading
  malware; attempting to exfiltrate other tenants' data; circumventing rate
  limits, size limits or abuse controls; using the service for unlawful
  purposes.
- Prohibition on using Principled output for employment, hiring, worker
  monitoring or individual developer performance ranking (kept distinct from
  code-quality analysis; see [ai-transparency.md](ai-transparency.md) and the
  AI Act notes in #28).
- Enforcement: suspension/termination, and how abuse is reported.
- Relationship to rate limiting, request/body size limits and secret
  redaction — these are engineering controls owned by the features that add
  them (#17), enforced here contractually.
