# Acceptable Use Policy

The public version of this policy is served at `/acceptable-use`. It must be
reviewed by qualified counsel before commercial launch.

**Classification:** Public.

## Permitted use

- Submit source code you are authorised to process.
- Use findings to support engineering review and learning.
- Report suspected vulnerabilities privately using the security address at
  `/imprint`.

## Prohibited use

- Upload credentials, private keys, malware or data you are not authorised to
  process.
- Attempt to access another user's submissions or bypass cache,
  authentication or abuse controls.
- Use the service for unlawful discrimination, employment screening, worker
  monitoring or individual developer performance ranking.
- Use automated traffic that degrades availability or materially exceeds
  ordinary interactive use.

## Enforcement

We may investigate abuse, limit requests, suspend access and preserve the
minimum information necessary to protect the service or comply with law. See
the [Terms of Service](terms-of-service.md) and [Privacy Notice](privacy-policy.md).
