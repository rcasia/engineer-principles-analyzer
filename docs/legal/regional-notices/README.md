# Regional notices

**Classification:** Public. Placeholder.

This directory holds jurisdiction-specific notices. It is **empty by design**.

A notice is added here only when a jurisdiction is **deliberately targeted**
or is **independently in scope** (operator establishment, the processing
activity itself, a contract, or the statute's own threshold) — never merely
because the public site is globally accessible (see
[../README.md](../README.md), "Territorial scope and market-targeting model").

The EU/Spain baseline is **not** a regional notice: it is the core baseline
and lives in the top-level legal documents.

Add a file here (e.g. `uk.md`, `california.md`) in the same commit as the
product decision that brings that jurisdiction into scope, recording the
concrete trigger and rationale.
